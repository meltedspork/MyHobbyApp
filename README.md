# MyHobbyApp
 
MyHobbyApp is a personal hobby project operated by [Your Full Name]. It sends reminders and alerts by text message to the owner's own mobile number using Twilio. It is not offered to the public and does not message any other users.
 
## SMS Program Summary
 
| Item | Details |
| --- | --- |
| Program name | MyHobbyApp |
| Message type | Reminders and alerts |
| Recipient | The account owner only, at their own mobile number |
| Message frequency | Varies, up to 5 messages per day |
| Cost | Message and data rates may apply |
| Opt out | Reply **STOP** at any time |
| Help | Reply **HELP**, or email [myhobbyapp.contact@gmail.com](mailto:myhobbyapp.contact@gmail.com) |
| Messaging provider | Twilio |
 
## How Consent (Opt-In) Works
 
1. The account owner opens the app's settings page.
2. They enter their own mobile phone number.
3. They check a consent box, which is **unchecked by default**, next to this text:
   > I agree to receive reminder and alert text messages from MyHobbyApp at the number provided. Message frequency varies, up to 5 per day. Message and data rates may apply. Reply STOP to opt out, HELP for help. See our [Privacy Policy](privacy.md) and [Terms](terms.md).
4. The number is saved only when the box is checked. No messages are sent before this step.
Step-by-step opt-in walkthrough with screenshots: [Opt-In Process](opt-in.md)
 
## Opting Out
 
- Reply **STOP** to any message. One confirmation is sent, then no further messages.
- Reply **HELP** for help.
## Data and Privacy
 
- We do not sell, share, or rent users' personal information to third parties.
- No mobile information will be shared with third parties or affiliates for marketing or promotional purposes.
- Text messaging originator opt-in data and consent will not be shared with any third parties.
- Information is passed to Twilio only as needed to deliver messages.
